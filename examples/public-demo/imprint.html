Access data

This site keeps an access log in which the client address is shortened before it is written (the last part is removed), so entries cannot be traced back to a person. It is used only to count how much the demo is used.

Cookies

This site sets one functional cookie, eudi_conformance, and only if you change the wallet's Conformance settings. It stores the validation strictness you chose so requests from your browser are held to it. It contains no personal data, is not used for tracking, and is not shared with third parties.

About this site

This is a shared public demo of the EUDI Dev Wallet. Anyone can issue and delete test credentials. All state is visible to all visitors and is reset periodically (see the footer of the wallet UI for the current schedule). Do not enter personal data.
