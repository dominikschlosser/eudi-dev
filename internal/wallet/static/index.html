How to use this wallet

This is a fully spec-compliant wallet: issuers and verifiers interact with it through the standard OpenID4VC protocols, OpenID4VCI for issuance and OpenID4VP for presentation. Point real issuers and verifiers at it and the flows run end to end, including holder binding, SD-JWT VC and mdoc formats, status lists, and trust lists.

Deliver a credential offer (OpenID4VCI)
/credential-offer?credential_offer_uri=…
Send an authorization request (OpenID4VP)
/authorize?client_id=…&request_uri=…
Trust list (verifiers trusting this wallet's credentials)
/api/trustlist

These endpoints take exactly the same query parameters as their custom-scheme counterparts (openid-credential-offer://, openid4vp://). To convert a custom-scheme link, replace everything before the ? with the endpoint URL and keep the query string.

Custom-scheme links via CLI (any platform)
eudi wallet accept 'openid4vp://authorize?client_id=…'
System URL handler (macOS)
eudi wallet register

wallet register installs OS handlers for openid4vp://, eudi-openid4vp://, haip-vp://, openid-credential-offer://, and haip-vci://, so clicking such links opens this wallet. See the wallet documentation for the full protocol surface.

Get the CLI

This wallet is the web UI of eudi-dev, a developer toolkit for the EUDI / OpenID4VC ecosystem. The eudi CLI decodes, issues, and presents credentials, runs this wallet locally, and proxies live wallet traffic.

Homebrew
brew install dominikschlosser/tap/eudi-dev
Go
go install github.com/dominikschlosser/eudi-dev@latest
Docker
docker pull ghcr.io/dominikschlosser/eudi-dev

Import Credential

Paste a raw SD-JWT or mDoc credential

Issue Credential

Issues a credential with the wallet's issuer key and imports it. All fields except the format are optional. Pick a template (for example german-pid-sdjwt) to fill everything. All values stay editable.

Credential Templates

Templates are reusable claim sets for issuing credentials. Pre-defined templates are built in. Saving a template under the same name overrides it. Paste template JSON below to import a shared template.
