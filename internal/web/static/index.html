Get the CLI

This decoder is part of eudi-dev, a developer toolkit for the EUDI / OpenID4VC ecosystem. The eudi CLI decodes, issues, and presents credentials, runs a local wallet with this decoder built in, and proxies live wallet traffic.

Homebrew
brew install dominikschlosser/tap/eudi-dev
Go
go install github.com/dominikschlosser/eudi-dev@latest
Docker
docker pull ghcr.io/dominikschlosser/eudi-dev
